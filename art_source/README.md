# Art sources

Original files from art packs, kept so the repository holds everything. The game does not load anything in this folder; it uses the packed atlases in `assets/` (built from these files, see `CLAUDE.md`).

- `movement_sprites/`: Movement Sprites pack (v63): every hero's battle strip (`assets/battle/heroes/<id>/on_foot|mounted/strip.png`), mounted map walker sheets and the pack manifest. Packed into `assets/battle/heroes/foot.png`, `mounted.png` and `assets/heroes/walkers_mounted.png`.
- `visual_upgrade/`: Visual Upgrade pack (v67): 25 battle strips, 47 on-foot walker sheets, portraits (128 and 256 px), spell and button icons, spell effects, the lit lighthouse, manifest and hero art coverage. Packed into `foot.png`, `walkers.png`, `recruits.png` and `assets/ui/upgrade.png`.
