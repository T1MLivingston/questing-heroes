# Assets

Sprite art for Questing Heroes, imported from Character Pack 01 and Headshot Workshop 02 (November 2026).

- `units/rangers/<unit>/<unit>_sheet.png`: battle atlases, 64×64 frames (Heartwood Elder 96×64), rows idle, move, attack, hit, death.
- `heroes/<id>/map/<id>_map_sheet.png`: map walk atlases, 48×48 frames, rows S, SW, W, NW, N, NE, E, SE.
- `portraits/heroes/<id>_64.png`, `_128.png`: hero portraits. Seven were converted from the workshop headshots (Boopis, Engelman, Grimes, Parker, Rago, Rimmer, Tempest).
- `portraits/units/<unit>_64.png`: recruit cards.
- `team_masks/`: paired masks; red channel 0/85/170/255 picks one of 4 team shades.
- `manifest.json`, `palette/master_palette.json`: the pack's registry and 64-colour palette.

See `LEGAL.md` for where this art came from.
